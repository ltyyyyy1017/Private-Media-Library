# 映屿 · Private Media Library

Windows 热点内使用的私人媒体库，手机、Mac 和 Windows 可通过浏览器访问。此仓库提供源码；运行时配置、证书、密码和共享文件不包含在仓库中。

源码运行：在 Windows 安装 Python，执行 `python -m venv .venv`、`.venv\Scripts\python -m pip install -r requirements.txt`，再双击“打开管理面板.cmd”。

# 热点文件柜（Windows 服务端）

## 单实例、托盘和设置记忆

管理面板与共享服务分别使用 Windows 命名互斥对象防止重复运行。重复双击程序会唤出已有面板；共享时单独的服务进程属于正常情况，并不代表打开了第二个管理面板。

关闭或最小化窗口会收至右下角托盘并继续共享。双击托盘图标打开面板；右键可开始共享、停止共享、复制地址、退出程序。灰色角标表示未共享，黄色表示启动中，绿色表示共享中，红色表示启动失败或共享中断。只有右键“退出程序”才会停止共享并退出。Windows 可能把托盘图标收进右下角上箭头，可在系统任务栏设置中让它始终显示。

默认记住共享文件夹与密码，保存在当前用户 LocalAppData\YingyuMediaLibrary\preferences.json。密码由 Windows DPAPI 按当前账户加密，不明文保存；更换 Windows 账户可能无法解密。可取消勾选或点击“清除记忆”移除保存的设置。程序不会把密码放进快捷方式或启动参数。登录 Windows 后仅启动一个托盘面板，不自动开启共享。

## 图片格式与原画质

支持 JPEG/JPG/JPE/JFIF、PNG/APNG、GIF、WebP、AVIF、BMP、TIFF、ICO、DIB、HEIC/HEIF/HIF、PSD、TGA、PPM/PGM/PBM/PNM、PCX；RAW 预览支持 LibRaw 能解码的 DNG（含苹果 ProRAW）、CR2/CR3、NEF/NRW、ARW/SR2/SRF、RAF、ORF、RW2、PEF、RAW。新机型或特殊 RAW 编码可能无法预览，仍可原样上传下载。

上传、保存、下载不压缩、不转码，原文件逐字节保留。GIF、动态 WebP、APNG（包括 .png 扩展名）直接返回原文件，保留动画。兼容预览另存为无损 PNG，不缩小分辨率；RAW 完整分辨率渲染为 16 位 PNG，高位深 HEIC 保留为 16 位预览。网页色彩和 HDR 显示受浏览器和屏幕影响，不能把网页预览视为 RAW 数据或完整 HDR 工作流的替代品。TIFF/HEIF 等多页或多帧兼容预览目前只显示首张，Live Photo 的照片和 MOV 分别浏览。

转换预览限制：源文件最多 256 MiB、图片最多 6400 万像素，同一时刻处理一张大图。超过限制不降画质，改为提示下载原文件。视频的小封面与视频源文件分开保存。SVG 等可能包含活动内容的格式仍只允许下载。

## Windows 打包版

手机图片/视频预览支持左右滑动切换同文件夹、同类型的上一个/下一个内容。向左滑动进入下一个，向右滑动返回上一个；小说、双指操作、图片放大状态及视频控制条上的操作不触发切换。到达列表边界会提示，不循环跳转。

安装位置：D:\app\映屿媒体库。双击桌面“映屿媒体库”快捷方式或目录中的 Yingyu.exe，无需另外安装 Python。已设置当前用户登录 Windows 后自动打开管理面板；不会自动开启热点或共享。关闭面板会隐藏到系统托盘；从托盘菜单退出可停止共享。要取消开机启动，按 Win+R 输入 shell:startup，删除“映屿媒体库”快捷方式。

新增卡片复选框及批量工具栏，可全选当前列表、批量移动、批量收藏、批量删除。每项独立执行，结果显示成功与失败数量，同名不会覆盖。删除功能把文件或整个文件夹移到原共享目录的隐藏子目录 .hotspot-trash，记录原路径；目前需要在电脑上打开该目录手动找回，不会自动清空，也不会释放对应磁盘空间。

预览图已升级为电脑端 FFmpeg 后台生成（随安装包提供），结果保存在共享目录 .hotspot-thumbnails。再次打开页面或换设备可复用已有封面，不再要求手机解码原视频。第一次生成仍需等待，损坏或无法解析的视频保留默认封面。此说明替代下文旧版的浏览器提帧方式。

## 映屿媒体库新版

登录页新增“记住登录 7 天”。登录凭据使用 Secure / HttpOnly / SameSite=Strict Cookie，不保存密码；不勾选则使用浏览器会话 Cookie，授权最长 2 小时。勾选后最长 7 天；同一共享目录和密码下重启服务仍有效，更换密码或共享目录会让旧登录失效。退出会清除当前浏览器登录。持有已复制 Cookie 的设备在到期前仍有权限，因此只在自己的设备上勾选。

手机 TXT 阅读使用铺满视口的阅读界面，默认收起工具栏，点击“阅读设置”显示字号、日夜模式、章节、编辑等操作。阅读字号和日夜偏好使用独立偏好 Cookie 保存，正文阅读进度仍保存在当前浏览器。适配动态地址栏高度及刘海屏安全区域。

新增文件卡片上的“移动”“改名”“收藏”：移动提供目标文件夹选择器，仅限共享目录内部，拒绝覆盖同名文件或把目录移入自身。播放器内也有移动与改名按钮。

“我的收藏”在电脑共享目录的隐藏元数据文件 `.hotspot-favorites.json` 中持久保存，同一共享目录的已授权设备共用收藏；该元数据不允许通过网页读取、上传或改名。网页操作移动、重命名文件或父文件夹后，收藏路径同步更新。直接在 Windows 文件管理器中移动文件不会同步收藏路径。

视频卡片现在按需提取预览帧，同时最多处理两个视频，当前页面缓存最多 120 张封面。不依赖外部图片服务或 FFmpeg；只有浏览器能解码的视频才能生成预览图，不支持的格式保留默认封面。此更新替代下文“未生成视频截图”的旧说明。

网页已升级为卡片式媒体库：视频、图片、TXT、其他文档分类；当前目录搜索、排序和文件夹导航；批量/拖放上传与进度显示；下载、重命名与新建文件夹。分类和搜索作用于当前文件夹，不是全盘索引。

视频使用随程序提供的 Video.js 8.23.4（https://github.com/videojs/video.js），许可证见 assets/VIDEOJS-LICENSE。支持倍速、全屏和当前浏览器续播，不访问外部播放器 CDN。视频卡片目前使用类型封面，未生成视频截图；不提供自动转码，不支持的编码需要下载后播放。

图片支持缩略图、放大、同目录前后翻阅。TXT 阅读上限现为 20 MiB，支持 UTF-8 和 GB18030、字号调整、夜间模式、常见中文章节跳转、当前浏览器阅读进度、编辑后另存新文件。PDF/Office 仍下载到本机应用查看。

升级后在电脑面板停止并重新开始共享，手机浏览器刷新页面并重新登录即可。

## 简单使用：双击管理面板

兼容性更新：热点识别使用 Windows WinRT 热点运行状态及唯一的活动 Wi-Fi Direct 网卡，不依赖旧版 ICS 枚举。仅要求当前使用的网络防火墙配置启用且默认阻止入站；切换网络后启动器重新检查。服务只绑定 IPv4 地址，不监听 IPv6。配置失败会显示具体阶段与错误，结果保存在 setup-result.json。

双击 `打开管理面板.cmd`。依次打开系统热点、点击“首次使用：配置访问隔离”（会出现 Windows 管理员授权提示）、选择共享文件夹、设置访问密码、点击“开始共享”。以后通常只需选择文件夹、设置密码并开始共享。点击“停止共享”或关闭管理面板都会结束由面板启动的服务。

管理面板是本机窗口，不对手机开放管理员功能。手机使用下方的网页地址管理共享文件。启动失败会在窗口显示错误；详细信息在 manager.log，其中不记录访问密码。证书信任仍需按下文完成，不能用跳过验证替代。

macOS、iOS、Windows 使用浏览器访问。支持文件夹浏览、新建、重命名、文件上传下载、图片和兼容视频预览、UTF-8 TXT 查看与另存编辑。PDF、Office 等下载后用对应应用打开。没有文档在线协同编辑和视频编辑功能。

## 安全范围与现状

只监听 192.168.137.1:8443；仅接受 192.168.137.0/24 来源；防火墙允许 ICS 热点私有接口，并明确阻断其他网卡和热点接口上的网段外来源。网络或防火墙配置变化时启动器会在约 2 秒内终止服务。使用 TLS 1.2+、每次运行重新设置的密码、登录限速、Secure/HttpOnly/SameSite Cookie、CSRF 检查和独立共享目录。拒绝路径穿越、符号链接、junction 和 NTFS ADS；网页类文件强制下载。重命名和上传不覆盖原文件。

“只有热点直连设备”依赖 Windows 防火墙和系统网络配置，不能给出脱离这些前提的绝对保证。管理员、恶意内核软件、热点设备代为转发/代理的连接，超出该程序能辨别的范围。IP 网段本身不证明设备身份。热点密码与文件访问密码应不同。仅在自己控制的设备上使用。不启用额外的桥接或端口转发。

尚未执行管理员防火墙配置或开启文件服务器，也没有修改你的系统网络设置。应用自动测试已覆盖基础访问控制；仍需完成下面的真实设备隔离验收后再放入敏感数据。此工具未经独立安全审计。

## 安装与启动

需要 Windows 10/11、Python 3.11+。本目录已创建依赖环境；移动到其他位置需重新安装：

```powershell
cd "程序所在的 HotspotFiles 文件夹"
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

1. 在 Windows 设置中开启“移动热点”，设置强密码。当前版本严格要求热点地址为 192.168.137.1/24；地址不同则拒绝启动。
2. 在**管理员 Windows PowerShell** 中进入程序目录，运行一次：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup-Firewall.ps1
```

该脚本通过 ICS 接口识别真实私有网卡，创建三个名为 HotspotFiles-* 的规则，仅影响 TCP 8443。如果系统不允许查询 ICS 或策略被组织管理，脚本会报错停止。不要通过放开所有网卡来规避错误。

3. 关闭管理员终端。在**普通 PowerShell** 中运行（使用自己创建的专用数据文件夹）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start.ps1 -ShareFolder "D:\手机共享"
```

输入至少 12 个字符的密码。每次启动都重新设置，不保存明文密码。不要直接运行 app.py，否则没有防火墙持续核对。

4. 手机或 Mac 连接电脑热点，在浏览器打开 **https://192.168.137.1:8443**，核对证书后输入密码。

首次使用生成自签名证书，浏览器不会自动信任。程序终端显示证书 SHA-256 指纹；请在可信电脑上核对浏览器证书信息。iOS 可以通过可信的有线或已验证渠道传送 private-state/server.crt 并安装和信任此证书；各 iOS 版本的证书配置流程不同。如无法核验证书或无法完成信任，不要输入密码或关闭安全检查。**绝不传送 server.key**。不能把“无条件忽略证书警告”作为安全使用步骤。

首次生成的证书和密钥存放 private-state；启动器用 NTFS ACL 限制为当前账户和 SYSTEM。证书有效期一年。共享文件夹中不要放程序目录、私人密钥或符号链接；运行期间不要让其他本地程序改动其目录链接。整个磁盘、用户主目录和程序目录不允许直接共享。

Ctrl+C 停止服务。电脑需要保持唤醒。单文件最大 4 GiB；TXT 编辑预览限制 1 MiB；上传文件大小仍受剩余磁盘空间限制。大视频支持 Range，但具体编码是否可播放由浏览器决定。普通文件修改可下载编辑后用新名称上传。

## 必须做的隔离验收

先用没有私人信息的文件夹测试：

- 手机连接热点：能登录、上传、浏览、下载、重命名和另存 TXT。
- 同一手机断开热点并改连家庭 Wi-Fi/移动网络：访问必须失败。
- 家庭路由器上的另一台设备访问电脑以太网/WLAN 的地址和 8443 端口：必须失败；即使配置到 192.168.137.1 的路由也必须失败。
- 热点设备使用错误密码、未登录下载、提交 ../ 路径：必须失败。
- 关闭热点或改变网卡/防火墙配置：启动器应停止服务器。监测有约 2 秒延迟，现有防火墙规则承担即时隔离。

我无法在你的手机或 Mac 上代替你完成这些跨设备验收，因此不能把“代码检查通过”描述成“已验证只有热点设备能访问”。

## 卸载防火墙规则

先停止服务，在管理员 PowerShell 中仅删除本程序三个规则：

```powershell
'HotspotFiles-Allow','HotspotFiles-BlockOther','HotspotFiles-BlockOutside' | ForEach-Object { Remove-NetFirewallRule -Name $_ }
```

保留共享数据文件夹；删除程序目录会删除证书与程序依赖，不会删除外部共享数据。

## 全库分类、精确查重与撤销

点击视频、图片、小说或其他分类，会列出整个共享文件夹及子文件夹中的文件，不移动原文件。全部文件仍按文件夹浏览，可用“切换全库视图”搜索全库名称和路径。收藏、批量移动和删除可用于全库列表。

“精确重复查找”必须手动开始，只用本机程序按大小、SHA-256、逐字节验证。不会联网或调用 AI，不会自动删除。结果仅存于服务进程内存，重启清空；修改文件后请重新扫描。查重读取文件可能占用磁盘时间。

“整理记录 / 撤销”按最近一次优先恢复本次更新之后的移动、改名、删除，批量操作可逐项撤销。记录存放共享根目录的隐藏应用元数据中。遇到目标同名、源文件变更或父目录消失会拒绝恢复，绝不覆盖。回收区不会自动清空。旧版本删除的文件仍保留原回收区，需要手工找回。

## 画质与视频兼容

原始文件始终原样提供下载和播放。图片点击切换原始像素查看，可滚动查看大图；兼容图片仍采用完整分辨率的 PNG，动图原格式播放。已经低清的原文件不能恢复不存在的细节。

视频扩展名识别增加 MKV、AVI、TS、MTS、M2TS、MPEG、MPG、WMV、FLV、3GP、OGV、VOB、M2V、MXF。无法直接播放时点击“无损兼容播放”，电脑生成 MP4 缓存，复制第一路视频和音频，不重新编码、不缩小画面、不降低码率。它只解决封装兼容问题；浏览器不支持的编码、HDR、音频或特殊格式仍可能需要下载原文件用本机播放器打开。不会为了兼容而静默进行有损转码。生成缓存需要额外磁盘空间。

视频封面改为最长边 1280 的 PNG，旧低清/失败缓存不会继续使用。失败可以重试，冷却 60 秒。封面是列表导航用缩略图，不代表播放画质；图片查看与视频播放均使用原文件或无损兼容文件。

## 重复查找改进

重复结果支持图片和视频封面、原地预览；关闭预览后返回原列表。删除一项保留其余结果。扫描结果与媒体指纹只存于共享目录下的隐藏应用元数据，重启后继续查看；外部修改或新增文件后应重新扫描。

“扫描相似图片 / 视频”使用 MIT 开源 benhoyt/dhash（https://github.com/benhoyt/dhash），图片比较感知指纹，视频在 10%、30%、50%、70%、90% 位置抽帧，结合时长、比例和多帧距离产生疑似候选。无需 AI、不联网。压缩或换格式可被发现，但剪辑、裁剪、字幕变化可能漏检，相似结果可能误报，必须人工预览确认。纯色或无法解码的画面会跳过；原始字节重复仍由精确模式检测。许可证见 assets/DHASH-LICENSE。

TS/MTS/M2TS 打开时自动生成无损 MP4 兼容缓存，保留原始音视频编码，修正时间戳并为 HEVC 标记 hvc1；编码或音频不被浏览器支持时仍需本机播放器。

## 视频标签

视频可添加多个标签，不需要移动到不同文件夹。列表上方“新建标签”创建标签，“管理标签”支持改名和删除（不删除文件）。视频卡片和播放器提供“打标签”，勾选多个视频后可“批量打标签”。选择标签会在全库视频中筛选，也可查看未打标签的视频。

标签只保存在本机共享目录的 .hotspot-tags 元数据中，多设备共用。基于 Windows 文件标识，程序内移动、改名和删除后撤销均保留关联；复制成新文件不会自动继承标签。请备份隐藏元数据以保留标签，跨磁盘迁移可能需要重新关联。

## 一键合并重复或相似组

扫描结果每组可选择“保留”的文件，再点击“合并本组”。确认窗口列出保留项及移入回收区的其他项；这会保留所选文件，不会拼接文件内容。疑似相似组请先逐个预览，不同剪辑可能有不同内容。合并不会自动把标签、收藏或其他文件的属性合到保留项。

合并前验证扫描时的文件标识、大小及修改时间，发生变化则拒绝处理，请重新扫描。旧扫描结果没有验证信息时也需重新扫描。遇到中途错误停止并报告已处理数量；已移入回收区的文件可在整理记录按倒序逐项撤销。

## 全部合并与标签多选

重复结果顶部“一键合并全部扫描结果”将一次处理所有组。默认每组保留第一项，可先调整各组保留项，再在一个总确认页检查所有保留项与回收项，一次确认执行。重叠组中的保留项受到保护，发生变化或错误时停止剩余处理，已处理项仍可逐项撤销。不会拼接文件内容或转移标签。

首页直接展示可搜索的标签区，支持多选、匹配任一或同时匹配全部、清空筛选和未打标签入口。卡片标签可直接点击筛选，封面提供标签快捷入口。打标签窗口支持搜索、多选后一次保存；多文件中部分已有的标签若未勾选修改，则维持原样。全部文件仍可访问，方便逐步标注。

## 图片和小说标签

图片、TXT 小说和视频共用标签，均支持单个和批量多选标注、播放或阅读窗口内标注、按多个标签筛选。先进入图片、小说或视频分类再选标签，可在该类型内筛选；全部文件视图可跨类型筛选。原有标签无需迁移。

人物自动分类目前仅完成开源方案调研，尚未安装模型或启用照片扫描。候选方案为 Immich 人脸分组（https://github.com/immich-app/immich）及 CompreFace（https://github.com/exadel-inc/CompreFace）。模型许可证须单独核查；启用前需由用户明确允许本地推理范围。

## 大型全库加载

切换全库时在后台建立索引，浏览器显示进度，每批读取 500 条元数据，标签按 300 项分批查询。页面先显示 120 项，可继续加载，搜索和标签筛选仍针对已加载的全库元数据。文件移动、上传、删除后索引失效，短期缓存减少重复遍历。资源管理器内更改资料后可点击“刷新全库索引”。索引只保存在服务内存中。

## 标签为主的导航

首页保留“全部文件”入口，默认展示全库，视频、图片、小说和其他文档的四个分类入口已移除。使用标签区搜索、多选分类；点击“文件夹浏览”可进入原始目录结构，点击“返回全部文件”回到全库。收藏、整理记录及重复查找入口保留。

## 苹果设备连接稳定性与证书

管理面板的健康检查改为每 5 秒完成一次已验证的 HTTPS HEAD 请求，旧证书使用精确证书指纹固定校验，新根证书使用完整链校验。列表图片仅在接近视口时加载，最多并发 2 张，图片加载超时会释放队列；标签信息就绪后只渲染一次，避免重复大图请求。服务器工作线程增加为 24。

若 Safari 持续提示连接失败，在管理面板点击“配置苹果设备证书”。这会重新签发证书并短暂重启原本运行的共享，导出程序目录中的“苹果设备根证书.crt”和安装说明。根证书私钥保留在受保护的 private-state 中，切勿传送任何 key 文件。导出的公钥根证书需通过可信渠道传到自己的设备，核对说明中的 SHA-256 指纹。iPhone 安装描述文件后，还须在 设置→通用→关于本机→证书信任设置 中开启 Yingyu Private Hotspot CA 完全信任。Mac 在钥匙串访问中导入证书，将 SSL 设为始终信任。关闭旧网页后重新访问热点地址。此操作不会自动执行，更新不会自动替换你已使用的证书。

Apple 官方说明：https://support.apple.com/en-us/102390 和 https://support.apple.com/en-ca/guide/keychain-access/kyca11871/mac 。

## 工作区布局与请求调度

首页按常用工具、标签和内容排列，支持列表/卡片切换。单文件操作位于“操作”菜单；批量操作先点击“批量选择”；文件夹浏览位于“浏览选项”，重复查找与撤销位于“整理工具”。标签筛选保持显眼，标签新建/管理收纳在“标签管理”。

图片转换忙时返回 503，避免阻塞全部服务线程；只读请求短暂失败可有限重试，写入请求不自动重发。视频封面复用已收到的数据，减少重复请求。原始媒体画质不变。
